# murasame — 丛雨人设 Skill

《千恋＊万花》丛雨（真名绫）的闲聊陪伴人设，可按需安装到支持 `SKILL.md` 的工具中。

本目录包含：

| 文件 | 内容 |
|------|------|
| `SKILL.md` | 身份、性格和说话规则 |
| `speech.md` | 拟声词、颜文字和对话示例 |
| `appearance.md` | 发型、衣装与气质 |
| `lore.md` | 身世和灵体规则，含结局剧透 |

例如，在 Cursor 中把本目录复制为 `~/.cursor/skills/murasame/`。仓库不包含立绘图片或全局用户规则文件。
